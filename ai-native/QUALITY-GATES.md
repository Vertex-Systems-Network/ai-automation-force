# Quality Gates

No content may enter the approved memory catalogue until every mandatory gate passes.

## Gate 1 — Classification completeness

PASS only if the item has:
- stable ID
- content type
- age band
- language
- objective
- target duration
- title and slug
- status

## Gate 2 — Age fit

Check:
- vocabulary difficulty
- sentence length
- conceptual complexity
- emotional intensity
- pace/duration
- instructions/behaviors a child might imitate
- whether the content is more appropriately directed to the parent than the child

For `baby-audio`, the content must be designed as parent-controlled audio and must not encourage infant screen engagement.

## Gate 3 — Child safety

FAIL if content normalizes or instructs:
- dangerous imitation
- self-harm or harm to others
- abuse, bullying, humiliation, or cruelty
- sexual or adult material
- substance use
- unsafe sleep/feeding/medical practices
- risky challenges/pranks
- secrecy from trusted caregivers in a manipulative context

For health, safety, or developmental claims, require reliable sourcing and conservative wording.

## Gate 4 — Coherence

PASS only if the content is easy to follow for the target age.

Stories need a clear beginning, middle, and resolution.
Educational pieces need one primary learning objective and a correct recap.
Songs/poems need understandable progression, not random rhyming lines.

## Gate 5 — Originality and duplication

Compare against repository memory and content.

FAIL on:
- exact or near-exact title reuse without intentional series labeling;
- materially same premise + hook + resolution;
- materially same chorus/refrain;
- distinctive phrase copying;
- obvious imitation of a protected character/song/universe;
- a concept selected mainly because a competitor already succeeded with the same execution.

Broad topics such as colors, numbers, sleep, friendship, animals, weather, and routines may recur only with a meaningfully different creative treatment.

## Gate 6 — Copyright/identity risk

FAIL if the item requests or relies on:
- celebrity or identifiable real-person voice imitation;
- copyrighted character imitation;
- lyrics copied from protected songs;
- modern recording/arrangement copying even when an underlying composition may be public domain;
- trademark confusion suggesting an official affiliation that does not exist.

## Gate 7 — Educational/factual integrity

If the content teaches a fact, check it.

FAIL on:
- invented facts presented as true;
- deceptively educational framing;
- oversimplification that becomes materially false;
- unsupported medical/developmental advice.

## Gate 8 — Language quality

Check:
- grammar
- pronunciation feasibility
- natural phrasing
- rhyme quality where relevant
- no accidental double meanings inappropriate for children
- localization-sensitive wording when language is not English

## Gate 9 — Audio readiness

PASS only if:
- exact performance text is frozen;
- pronunciation notes are present if needed;
- section boundaries are clear;
- voice direction is age-appropriate;
- pace/tone/energy are specified;
- no real-person imitation is requested;
- Gemini handoff does not claim unsupported musical capability.

## Gate 10 — Platform-quality risk

Check for characteristics associated with low-quality mass-generated kids content:
- confusing/jumbled story
- unclear educational value
- misleading title/claim
- excessive repetition without creative purpose
- bizarre/sensational material
- keyword stuffing
- aggressive promotion

A content item must have a clear reason to exist beyond filling a publishing slot.

## Gate 11 — Metadata and traceability

PASS only if research provenance, duplicate-review notes, safety review, and version/status are recorded.

## Gate 12 — Final recheck

Immediately before save:
- re-run duplicate comparison on final text;
- verify package path does not collide;
- verify memory ID is unused;
- verify no mandatory gate is unresolved.

Only then set status to `approved`.
